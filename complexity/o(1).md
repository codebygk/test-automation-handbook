# O(1) - Constant Time

## Definition

**O(1)** means the operation takes a constant amount of time regardless of the input size.

```text
Input size increases
        |
        v
Execution time stays approximately constant
```

## Example

```python
def get_first(numbers):
    return numbers[0]
```

Whether the list has:

```text
10 elements
1,000 elements
1,000,000 elements
```

Accessing `numbers[0]` is still O(1).

## Common Examples

```python
numbers[5]              # List index access
dictionary["name"]      # Dictionary lookup - average O(1)
value in my_set         # Set membership - average O(1)

stack.append(value)     # O(1) amortized
stack.pop()             # O(1)
queue.append(value)     # O(1) with deque
queue.popleft()         # O(1) with deque
```

## Example

```python
numbers = [10, 20, 30, 40, 50]

print(numbers[3])
```

The list does not need to be traversed:

```text
[10] [20] [30] [40] [50]
              ^
              |
          direct access
```

Therefore:

```text
Time: O(1)
Space: O(1)
```

## O(1) Does Not Mean Instant

O(1) means the operation's complexity **does not grow with input size**.

For example:

```python
def calculate():
    a = 10
    b = 20
    c = 30
    return a + b + c
```

The amount of work is fixed, so it is O(1).

## O(1) vs O(n)

| O(1) | O(n) |
|---|---|
| Constant growth | Linear growth |
| Input size doesn't affect complexity | Work grows with input size |
| `numbers[0]` | Linear search |
| Dictionary lookup, average | List search |

```text
O(1)

Time
 ^
 |  ---------
 |
 +--------------> Input size


O(n)

Time
 ^
 |       /
 |     /
 |   /
 | /
 +--------------> Input size
```

## Interview Question

**What is O(1) time complexity?**

> "O(1) means constant time. The amount of work does not grow with the size of the input. For example, accessing an element of a Python list by index is O(1)."

## Important Point

```text
O(1)
does NOT mean
"one operation"

It means
"constant growth with respect to input size"
